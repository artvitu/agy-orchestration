# Двухэтажная оркестрация агентов в Google Antigravity

Когда задача требует разделения ролей (например: разработка, тестирование, независимое ревью, документация), выбирай этаж оркестрации по масштабу и изоляции контекста:

1. **Постоянные ролевые субагенты внутри текущей сессии (нижний этаж, основной инструмент для модульной работы):**
   - Используй `define_subagent` + `invoke_subagent` (для быстрых проверок передавай `Model: "flash"`), сохраняй возвращённый `conversationId` роли в план задачи и на следующих раундах правок обращайся к **тому же** субагенту через `send_message`.
   - Субагент сохраняет свою историю и горячий промпт-кэш (`88-96%`) на диске даже после сжатия контекста (`/compact`) родительской сессии и не занимает место в левой боковой панели.
   - Полные отчёты и код субагент пишет в файлы на диске, а в родительский чат возвращает короткую выжимку на 10-20 строк.

2. **Одноразовый "холодный читатель" (контрольная приёмка):**
   - Перед финальной сдачей важного кода или документа вызывай нового одноразового субагента `research` без предыстории обсуждений: передавай ему только путь к готовому файлу и критерии проверки (`Builder != Verifier`).

3. **Самостоятельные сессии в левой боковой панели (верхний этаж, межчатовая связь):**
   - Когда нужны параллельные долгоживущие сессии направлений/модулей или передача эстафеты между открытыми вкладками Antigravity, открой навык `agy-orchestration` и используй его скрипт `agy-wake.py`.
   - Всегда проверяй статус получателя: в работающую сессию (`RUNNING`) отправляй только с флагом `--queue` (`WHEN_IDLE`), длинные задания передавай через `--body-file`, указывай `--from <своя-роль>` для включения 60-секундного кулдауна анти-петли (`--cooldown 60`) и не буди сессии вхолостую при остатке квоты пула `<= 10%`.

4. **Рой `/swarm`:**
   - Включай только по явному запросу пользователя на параллельный мозговой штурм с общей доской сообщений, учитывая повышенный расход подписочной квоты.
