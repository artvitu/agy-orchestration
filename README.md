# Плагин `agy-orchestration` для Google Antigravity Desktop (2.34+ / 2.35+)

Готовый пакет двухэтажной оркестрации ИИ-агентов для **Google Antigravity Desktop**:
- **Верхний этаж (связь между вкладками в левой панели `Projects`):** скрипт `agy-wake.py` через локальный RPC самого `Antigravity` находит все сессии проекта (включая выгруженные после перезапуска IDE `2.35+` в режиме ленивой загрузки `enableLazyLoad`), адресует их по слагам ролей **на лету без обязательного реестра**, при необходимости подгружает закрытую вкладку через `LoadTrajectory`, будит спящие (`IDLE`), ставит поручения в очередь занятым (`RUNNING` -> `WHEN_IDLE`) без сброса выбранной модели и создаёт новые рабочие вкладки сразу внутри папки проекта с пресетом `TURBO`.
- **Нижний этаж (команда специалистов внутри одной сессии):** правила и рецепты работы с постоянными ролевыми субагентами (`define_subagent` + `invoke_subagent` + `send_message`), которые удерживают память роли и `88-96%` горячего кэша даже после сжатия контекста (`/compact`) родительской вкладки.

Никаких внешних библиотек ставить не нужно - используется только стандартная библиотека `Python 3.10+`.

## Требования и ограничения
- **Запущенный `Google Antigravity Desktop 2.34+ / 2.35+`** с открытым проектом (скрипт обращается к локальному процессу `language_server` запущенной IDE и не стартует закрытое приложение сам).
- **Поведение после перезапуска IDE (`2.35+` lazy load):** после рестарта `Antigravity` метод `GetAllCascadeTrajectories` отдаёт только открытые в этом запуске вкладки, а остальные сессии лежат на диске (`~/.gemini/antigravity/conversations/*.db`). Начиная с `v1.1.0`, `agy-wake.py` автоматически добирает выгруженные сессии через `SearchConversations` (показывает их со статусом `ON_DISK`) и перед проверкой статуса или отправкой сам загружает адресата в память `language_server` через `LoadTrajectory` без ручного клика пользователя.
- **`Python 3.10+`** в системном `PATH`.
- **ОС:** проверено вживую на **macOS** (включая обход сетевой песочницы Seatbelt). На Linux пути `~/.gemini/antigravity/daemon/hub_*.json` совпадают по структуре `Path.home()`, но на Linux и Windows живые проверки пока не проводились.
- **Рабочий каталог при вызове из терминала:** запускай `agy-wake.py` из папки целевого репозитория (скрипт сам определит проект по имени папки) либо передавай явный флаг `--project <имя_проекта>`.

## Установка за 1 минуту

Склонируй репозиторий напрямую в одну из двух папок (либо распакуй архив):

1. **Только для одного проекта (рекомендуется для командного репозитория):**
   ```bash
   git clone https://github.com/artvitu/agy-orchestration.git .agents/plugins/agy-orchestration
   ```
2. **Глобально для всех проектов на компьютере:**
   ```bash
   git clone https://github.com/artvitu/agy-orchestration.git ~/.gemini/config/plugins/agy-orchestration
   ```

Обновлять плагин можно обычным `git pull` внутри установленной папки. `Antigravity Desktop` подхватывает плагин автоматически со следующего хода агента (перезапуск IDE не нужен; управлять включением можно в разделе `Customizations -> Plugins`).

## Быстрый старт (3 шага)

### Шаг 1. Работа в безопасном режиме `Auto` (через встроенные `hooks.json`) и опциональный `TURBO`
Встроенная сетевая песочница macOS по умолчанию блокирует прямые TCP-запросы из `run_command` на `127.0.0.1` (`Operation not permitted`). Плагин включает собственный корневой `hooks.json` (`SessionStart`, `PostToolUse`, `PreInvocation`):
- В безопасном режиме `Auto` команды чтения (`list`, `find`, `status`) автоматически читают свежий снимок от хоста, а `send ... --yes` доставляется хуком `PostToolUse` сразу после завершения команды (результат приходит модели в следующем шаге `PreInvocation`).
- Если нужен прямой вызов без очереди моста (включая `spawn`, `preset`, `delete` или `send --wait` изнутри чата), можно перевести конкретную вкладку в режим `TURBO` из обычного терминала macOS. Важно: режим `TURBO` включает автовыполнение команд без окон подтверждения; вернуть стандартный режим можно флагом `--preset auto`:

```bash
python3 .agents/plugins/agy-orchestration/skills/agy-orchestration/scripts/agy-wake.py list
python3 .agents/plugins/agy-orchestration/skills/agy-orchestration/scripts/agy-wake.py \
  preset --to "<часть заголовка вашей вкладки>" --preset turbo --yes
```

*(Если плагин установлен глобально, замени начало пути на `~/.gemini/config/plugins/agy-orchestration/...`.)*

### Шаг 2. Дай ролям маркеры (реестр больше не обязателен)
Отдельный файл реестра вести не нужно: если у вкладки в заголовке есть префикс вроде `[backend] API` или `[qa] Тесты` либо в начале переписки указан тег `[role:backend]` / `/resume-chat backend`, то `agy-wake.py send --to qa ...` найдёт сессию и подгрузит её с диска на лету сам.

Если вкладки названы произвольно (без тегов) или нужно вручную развести две вкладки с одинаковой ролью, попроси агента один раз собрать опциональный локальный кэш-реестр (сохраняется в `~/.gemini/antigravity/cache/agy-wake/sessions-<проект>.json`, не засоряя `git status` репозитория):
> *"Используй навык agy-orchestration: покажи все сессии нашего проекта (включая ON_DISK) и привяжи роли к вкладкам без тегов."*

Агент выполнит `agy-wake.py discover --from-titles --sync --yes` или `bind --slug <роль> --to <заголовок> --yes`.

### Шаг 3. Передавай задачи между вкладками и субагентами
Теперь любая вкладка с пресетом `TURBO` (а также любой внешний скрипт или агент из другой IDE на этой же машине!) может:
- отправить задание соседней вкладке (если та занята - сообщение аккуратно встанет в очередь `WHEN_IDLE` и запустится сразу после окончания её текущего хода):
  ```bash
  python3 .../scripts/agy-wake.py send --to qa --from backend --queue --body-file task.md --yes
  ```
- создать новую вкладку сразу внутри вашего проекта `Projects -> <имя>` с готовым пресетом `turbo` и привязкой роли:
  ```bash
  python3 .../scripts/agy-wake.py spawn --title "[review] Инспектор кода" --slug review --preset turbo --text "Проверь последний коммит" --yes
  ```

## Дисклеймер
Инструмент опирается на внутренний локальный Connect-RPC (`LanguageServerService`) запущенного `Antigravity Desktop 2.34+`, который официально не заявлен вендором как публичный стабильный API и может измениться в следующих мажорных версиях IDE.

## Встроенные защиты
- **Dry-run по умолчанию:** без флага `--yes` любая пишущая команда только показывает предпросмотр.
- **Не сбивает выбранную модель:** при `send` без `--model` модель, выбранная пользователем в выпадающем списке вкладки-получателя, остаётся нетронутой.
- **Анти-петля и защита от самоотправки:** флаг `--from <роль>` запрещает случайно разбудить самого себя и ставит 60-секундный кулдаун на повторный пинг одной и той же пары вкладок.
- **Защита подписочного пула (`> 10%`):** перед пробуждением проверяется остаток 5-часовой и недельной квоты соответствующего пула (`Gemini Models` или `Claude and GPT models`). При падении остатка до `10%` и ниже автопробуждение останавливается.
